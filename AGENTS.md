# AGENTS.md

Резюме-лендинг «Подъём»: Vite 8 + TypeScript без фреймворка, Three.js (WebGL2), GSAP + ScrollTrigger, Lenis, npm, Node 22. Комментарии и доки — на русском; идентификаторы, коммиты и ветки — на английском.

Этот файл — главный файл правил для агентов. `CLAUDE.md` только подключает его.

## Главное

- **Контент первичен:** всё резюме — в `index.html` и читается без JS и без WebGL; 3D — декоративный слой поверх (`aria-hidden`).
- **Одна переменная:** прогресс скролла `0..1` управляет всей сценой и высотомером; обратный скролл перематывает, отдельной логики «назад» нет.
- **Бюджеты не превышать** (таблица в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#бюджеты)); вырос бандл или ассет — сказать сразу.
- **После правок:** `npm run build` (typecheck + сборка) и проверка в браузере, если менялись UI или сцена.
- Код — источник истины: если док разошёлся с кодом, док правится в том же коммите.
- Объём задачи не расширять молча; неоднозначность — спросить.

## Код

Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); здесь только выжимка.

- **Слои:** `content/site.json` → `scripts/content-plugin.ts` + `src/content/render.ts` (HTML при сборке) → `src/main.ts` (критический путь) → `src/motion.ts` (Lenis, GSAP) и `src/experience/` (Three.js) → `src/shaders/`. `src/content/altitude.ts` — чистая логика без DOM и Three.
- **Начальный бандл — только `main.ts`** (~2,4 КБ gzip). Lenis и GSAP — только в `motion.ts`, Three.js — только в `src/experience/`; оба подключаются через `import()` по первому взаимодействию. Статический импорт их в `main.ts` ломает Lighthouse.
- **Внутренние ссылки** не обрабатывать отдельно: общий обработчик в `main.ts` ведёт все `a[href^="#"]` и `[data-return]` через `travelTo`.
- **Новый объект сцены** читает прогресс через `setProgress(p)`, своих слушателей скролла не вешает.
- **Генерация в `src/experience/terrain/`** — чистые функции без three.js и DOM (её выполняет воркер). Числа рельефа меняются там же, сид — `TERRAIN_SEED`.
- **Цвета сцены** — только в `palette.ts` (небо, туман, свет) и в палитре `generate.ts` (рельеф). Ключи на 0 м держать в паре с градиентом `html` в `main.css`.
- **Каждый кадр:** без аллокаций (`new Vector3` и т. п. — в поля класса), без `querySelector`, без чтения layout.
- **DOM-анимации** — только `transform` и `opacity`; анимации скролла — `scrub`, чтобы откатывались.
- **Ресурсы Three** (`geometry`, `material`, `texture`, `renderer`) — освобождать в `dispose()`.
- **Шейдеры** — отдельные `.vert` / `.frag` в `src/shaders/`, uniform-ы с префиксом `u`, varying — `v`.
- **Модели** — только после `npm run models` (meshopt, WebP ≤ 1K); сырые файлы — в `assets-src/`, не в `public/`.
- **Доступность:** `prefers-reduced-motion` и «Классическая версия» отключают 3D и полёт; декоративные дубли текста — `aria-hidden`.
- **Контент — данными, не разметкой:** тексты сайта (включая подписи кнопок в `ui`) — в `content/site.json` по zod-схеме `src/content/schema.ts`, HTML генерируется при сборке. Строки контента прямо в шаблоны не писать — иначе будущая админка их не увидит. Новое поле — сначала в схему, потом в JSON и `render.ts`. Подробно — [ARCHITECTURE § Контент и будущая админка](docs/ARCHITECTURE.md#контент-и-будущая-админка).
- **Стиль:** 2 пробела, без `;`, одинарные кавычки. Комментарий — одно предложение про «почему».

## Данные и приватность

- Персональные данные — только в `content/resume.md` (в `.gitignore`). В код, коммиты, доки и логи их не копировать сверх того, что уже опубликовано на сайте.
- На публичный сайт по умолчанию — имя, роль, email, Telegram, GitHub. Телефон и дата рождения — только по явному решению владельца.

## Git

- **Агент не коммитит и не пушит** — это делает владелец. Изменения остаются в рабочей копии, в конце задачи — список изменённых файлов.
- Ветка по умолчанию — `main`, remote — `github.com/zairziyamdun/portfolio-z`. Крупный этап из ROADMAP — отдельная ветка `feat/<этап>`.
- Коммиты — простой английский с префиксом: `feat:`, `fix:`, `style:`, `refactor:`, `perf:`, `docs:`, `chore:`. **Без атрибуции ИИ**: без строк `Co-Authored-By` и подписей Claude.
- Перезапись истории (`--force`, `rebase` опубликованных коммитов) — только по просьбе владельца.

npm run models      # assets-src/models/*.glb → public/models (gltf-transform)
