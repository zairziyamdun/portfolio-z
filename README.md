# Portfolio — Ascent

Резюме-лендинг: подъём от базового лагеря на вершину и дальше на орбиту.
Контент живёт в HTML и читается без JS, 3D-слой загружается отдельным чанком поверх.

Правила для агентов — [AGENTS.md](AGENTS.md), документация — [docs/](docs/).

## Команды

```bash
npm install
npm run dev       # локальный сервер
npm run build     # проверка типов + продакшн-сборка в dist/
npm run models    # оптимизация моделей из assets-src/models → public/models
```

## Структура

```
index.html                  весь контент резюме (SEO, без JS тоже работает)
src/main.ts                 скролл (Lenis), высотомер, анимации, возврат, ленивая загрузка 3D
src/content/altitude.ts     нелинейная шкала: прогресс скролла → метры, зоны
src/experience/             Three.js: сцена, уровни качества
src/shaders/                GLSL
src/styles/main.css         стили, классический режим, reduced-motion
assets-src/                 сырые модели из Meshy/Blender (в git не попадают)
public/models, textures     оптимизированные ассеты
scripts/optimize-models.mjs пайплайн gltf-transform
```

## Принципы

- Одна переменная — прогресс скролла 0..1 — управляет всей сценой; обратный скролл перематывает.
- Быстрые переходы («Вернуться на Землю», «Связаться сразу») идут под шторкой, промежуточные сцены не рендерятся.
- Уровни качества по устройству, адаптивное разрешение, пауза рендера на скрытой вкладке.
- `prefers-reduced-motion` и «Классическая версия» отключают 3D.
